**A task-first map of algorithm & data-structure implementations across programming languages.** Need a max-flow solver, an FFT, a convex hull, a Raft implementation? Look up the *task*, get the best repos in any language. (411 repos, last refreshed 2026-11-09)

> **Українською:** індекс реалізацій алгоритмів і структур даних, організований **за задачею**, а не за мовою. Кожен пункт — посилання на оригінальний репозиторій GitHub. Індекс оновлюється автоматично через офіційний GitHub Search API (див. [`tools/collect.py`](tools/collect.py)).

## 🔁 How the index is built

- Collected automatically via the official **GitHub Search API** (`tools/collect.py`), curated (`tools/curate.py`), rendered by `tools/gen_readme.py` (data in `data/repos.json`).
- Filters: stars ≥ 40, not archived, deduplicated across categories. Snapshot: **2026-11-09**.
- Browsed **by task** (compression, graphs, hashing, geometry, DSP...), so you search by what you want to build — the Lang column tells you which language each implementation uses.
